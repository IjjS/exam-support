# 자료함

[English guide](README.md)

시험 자료를 등록 전이나 후에 이곳에 넣으세요. `/exam-init`은 시험 범위 지도와 기출 문제은행을 만들 때 사용하고, `/exam-harvest`는 학습 자료를 개념 노트로 정리할 때 사용합니다. 파일명에 시험명을 넣으면 자료를 해당 시험에 연결하기 쉽습니다. 파일명이 모호하면 확인이 필요할 수 있습니다.

**기출문제가 특히 유용합니다.** `/exam-init`은 각 문항과 제공된 정답을 문제은행에 저장하고, 토픽에 연결하며, 문제 형식과 난이도를 실제 문항에 맞춥니다. 이후 `/exam-quiz` 소스 모드로 저장된 문항을 순서대로 풀 수 있습니다. 등록 후 구한 기출은 `/exam-init --bank`로 추가합니다.

```text
_inbox/
├── AWS_SAP_past_questions_2024.pdf
├── AWS_SAP_exam_guide.pdf
└── AWS_SAP_lecture_notes.md
```

처리한 파일은 `exams/{slug}/_sources/`로 복사합니다. `_inbox/`의 원본은 남깁니다.

## 지원 자료

| 형식 | 처리 방법 |
|---|---|
| URL | 대화에서 링크 전달 |
| PDF | 구조화된 가이드와 기출문제에 권장 |
| MD, TXT | 직접 읽음 |
| DOCX, XLSX, PPTX | 문서, 스프레드시트, 슬라이드 자료 |
| PNG, JPG | 개별 페이지 사진 또는 스캔 |
| HWP | 읽을 수 없으므로 먼저 PDF로 내보내기 |

대화에서 파일 경로, URL, 첨부 파일을 직접 전달해도 됩니다. 분량이 있는 자료는 사용 전에 시험별 `_sources/`에 저장합니다.

## 자료별 처리 결과

| 자료 | 스킬 | 결과 |
|---|---|---|
| 시험 가이드·출제기준 | `/exam-init` | `blueprint.md`에 영역과 영구 토픽 ID 기록 |
| 기출문제 | `/exam-init` 또는 `/exam-init --bank` | `_sources/questions/`에 문제 원문과 제공된 정답 저장; 토픽 연결과 형식 보정 |
| 교재·강의 노트·문서 | `/exam-harvest` | `notes/`에 출처가 있는 개념 노트 작성 |
| 시험 공고 | `/exam-init` | `exam.md`에 시험 정보 기록 |

등록 후 시험 가이드를 추가했다면 `/exam-init --refine`으로 토픽 지도를 수정하거나 `/exam-init --format`으로 문제 형식을 갱신하세요. Harvest는 노트를 만들며 시험 범위 지도나 문제 형식은 변경하지 않습니다.

사용자 제공 파일을 웹보다 먼저 검색하지만, 제공된 정답도 채점에 영향을 줄 때는 검증할 주장으로 취급합니다. 자세한 규칙은 [출처 정책](../_spec/source-policy.md)을 참고하세요.
